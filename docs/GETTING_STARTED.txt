  ──────────────────────────────
  TRACK_ALL_COINS=false
  SELECTED_COINS=BTC,ETH,SOL,ARB

  Option 2: Track all available coins
  ────────────────────────────────────
  TRACK_ALL_COINS=true

  Other settings:
  ───────────────
  NETWORK=mainnet              # or testnet
  DASHBOARD_PORT=5000          # Change if needed
  BATCH_SIZE=1000              # Performance tuning
  DEDUP_INTERVAL=60            # Flush interval (seconds)

  The system will:
  • Stop accepting new trades
  • Flush all pending addresses to database
  • Display final statistics
  • Exit cleanly

  ─────────────────────────

  Connection issues?
  ──────────────────
  • Check internet connection
  • Try testnet: NETWORK=testnet in .env
  • Review logs for details
